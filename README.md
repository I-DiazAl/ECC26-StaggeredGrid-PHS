# ECC26-StaggeredGrid-PHS

Animations for a paper "Structure preserving discretisation method for 2D Port-Hamiltonian systems using finite differences on staggered grids".

File _TimoshenkoBeam_1D_Simulation.gif_ shows an animation of the flexible beam discretization proposed on the paper, along a dynamic graph of the energy and the end-tip of the beam.

File _MindlinPlate_2D_Simulation.gif_ shows an animation of a Mindlin plate model as presented in [17]. More precisely, we consider a rectangular aluminium plate 3(mm) thick clamped along one edge, with the two opposite edges free and the remaining edge supporting a mass suspended from a single off-center point. The animation shows the discretization of a 6x6 grid, along a dynamic graph of the energy.

File _ConnectionCoef.mat_ presents matrix I_1^{(p)}, I_2^{(p)} and I_0^{(p)} along with I_1^{(u)}, I_2^{(u)}, I_0^{(u)} and I^{(up)} used for the discretization of the Mindlin plate.

[17] C. Ponce, Y. Wu, Y. Le Gorrec, and H. Ramirez, “A systematic methodology for port-Hamiltonian modeling of multidimensional flexible linear mechanical systems,” Applied Mathematical Modelling, vol.134, pp. 434–451, 2024.
